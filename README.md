# Archer — سایت معرفی ایجنت برنامه‌نویس

سایت استاتیک (HTML/CSS/JS خالص، بدون build و بدون وابستگی) برای معرفی ایجنت «آرچر».
تم مشکی–قرمز HUD، فارسی و راست‌به‌چپ، انیمیشن‌دار و ریسپانسیو.

## ساختار

```
archer_site/
├── index.html        ← تمام محتوا (هیرو، قابلیت‌ها، چگونه کار می‌کند، نمونه‌کار، سازنده، فوتر)
├── css/style.css     ← تم، گرید HUD، کارت‌ها، ریسپانسیو (clamp)، prefers-reduced-motion
└── js/
    ├── hero-core.js  ← هسته قرمز چرخان + ذرات/خطوط روی canvas (DPR محدود، کاهش ذرات در موبایل)
    └── main.js       ← افکت تایپ، اسکرول نرم، reveal، منوی موبایل، شمارنده، دکمه بازگشت به بالا
```

## اجرا

```bash
# سرو محلی (فقط loopback)
python3 -m http.server 8780 --bind 127.0.0.1 --directory archer_site
# → http://127.0.0.1:8780
```

یا با اسکریپت که هم‌زمان تونل عمومی می‌سازد:

```bash
bash run_site_tunnel.sh
# لینک عمومی در archer_site_url.txt نوشته می‌شود (هر بار restart عوض می‌شود)
```

## تست

```bash
python3 test_archer_site.py   # سرو محلی + وجود فایل‌ها + اسکن محتوا + چک اسکرول افقی
python3 check_html.py         # توازن تگ‌ها، id یکتا، لنگرها، نبود JS خارجی، نام سازنده
```

## ویرایش محتوا

متن‌ها مستقیم در `index.html` هستند؛ رنگ‌ها در `:root` داخل `css/style.css`:

```css
--red:#ff2d3f;   /* رنگ اصلی */
--bg:#07060a;    /* پس‌زمینه */
```

## یادداشت‌ها

- فونت‌ها (Vazirmatn / Orbitron / JetBrains Mono) از Google Fonts لود می‌شوند؛
  اگر اینترنت نبود، fallback سیستمی استفاده می‌شود و سایت خالی نمی‌ماند (`font-display: swap`).
- کلمات تکنیکال انگلیسی با `dir="ltr"` جدا شده‌اند تا در متن فارسی به‌هم نریزند.
- اگر تونل مرده بود یا لینک باز نشد: `bash run_site_tunnel.sh` را دوباره اجرا کن.
- سازنده: **غفور مدیرزاده**
